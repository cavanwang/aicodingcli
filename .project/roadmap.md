## 实施策略
1. **策略先行**：先做 prompt 级策略注入（任务 A），再做工具建设（B/C）
2. **存量变现**：优先封装已有代码（ast_analyzer.py、project.py import 提取）
3. **API 优先**：嵌入能力用 DashScope API，避免本地重型依赖
4. **自举验证**：每任务完成后用本仓库做端到端回归

## 风险控制
- embedding API 不可用 → 自动降级关键词搜索
- 大文件检索失真 → AST 函数级分块，不做整文件向量
- 符号工具误报 → ast_analyzer 已声明轻量实现边界（不处理动态属性/闭包），工具描述中明示
- 上下文压缩丢信息 → 保留最近 N 轮原文 + 结构化摘要
